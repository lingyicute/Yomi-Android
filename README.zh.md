# Yomi

![image](https://github.com/lingyicute/Yomi-Web/blob/main/icons/Icon-192.png)

[简体中文] | [English](./README.md) 

[Yomi](https://yomi.92li.uk) 是一款基于 [Flutter](https://flutter.dev) 构建的开源 [Matrix](https://matrix.org) 客户端。怀揣着 [Fluffychat](https://github.com/krille-chan/fluffychat) 的设计愿景，Yomi 致力于成为一款自由且简单易用的即时通讯工具。

## 功能特性

- 📩 发送各类文本消息、图片与文件
- 🎙️ 语音消息
- 📍 位置共享
- 🔔 消息推送通知
- 💬 无限制的私密与公开群聊
- 📣 支持数千人同时在线的公共频道
- 🛠️ 功能丰富的群组管理工具
- 🔍 发现并加入公共群组
- 🌙 深色模式
- 🎨 Material You 设计风格
- 😋 自定义表情符号与贴纸
- 🌌 空间（Spaces）功能支持
- 🔄 与其他 Matrix 应用全面兼容互通
- 🔐 端到端加密（E2EE）
- 🔒 加密聊天记录备份
- 😀 表情符号验证与交叉签名（Cross-signing）

... 以及更多功能。
